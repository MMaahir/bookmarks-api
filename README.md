# bookmarks-api

A bookmark saver API. Boring on purpose: it's the vehicle for learning
platform engineering, with CI, containers, Terraform, Kubernetes, GitOps,
and observability built around it stage by stage.

The project plan, working agreements, and stage progress live in
[AGENTS.md](AGENTS.md). Per-issue learning notes accumulate in
[docs/journal](docs/journal/).

Current status: stage 1 of 9, app and image.
